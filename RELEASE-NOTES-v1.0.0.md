# Drooly Desktop v1.0.0 — Maple City + WetDrool

First desktop release. Both games as native apps for **macOS, Windows, Linux** —
thin hardened shells over the live web games, so every web update ships to
desktop instantly.

## Cross-device multiplayer
One cloud moshpit (Cloudflare Durable Objects) shared by **web, desktop, and
Solana Seeker** — desktop players drop into the same rooms as everyone else.

## Downloads
| Platform | Maple City (SFW) | WetDrool (18+) |
| -------- | ---------------- | -------------- |
| macOS Apple Silicon | `Maple.City-1.0.0-arm64.dmg` | `WetDrool-1.0.0-arm64.dmg` |
| macOS Intel | `Maple.City-1.0.0.dmg` | `WetDrool-1.0.0.dmg` |
| Windows | `Maple.City.Setup.1.0.0.exe` (or portable) | `WetDrool.Setup.1.0.0.exe` |
| Linux | `Maple.City-1.0.0.AppImage` | `WetDrool-1.0.0.AppImage` |

- macOS builds are **unsigned**: right-click → Open on first launch.
- WetDrool is **18+** — the in-game age gate is enforced.
- Renderer crashes are logged to `crash.log` in the app-data folder.
